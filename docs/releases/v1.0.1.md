Windows 자동 실행과 트레이 전용 시작을 추가한 **LumaDock 1.0.1**입니다.

## 변경 사항

- **Windows 시작 시 자동 실행:** 현재 사용자 로그인 시 실행됩니다. 기본값은 켜짐이며 **설정 → 실행**에서 켜고 끌 수 있습니다.
- **트레이에서 시작:** 자동 실행할 때 본창을 표시하지 않습니다. 직접 실행할 때도 트레이로 시작할지 설정할 수 있습니다.
- **본창 열기:** 트레이 오른쪽 메뉴의 **LumaDock 열기**, 또는 이미 실행 중인 앱의 바로가기를 다시 실행하면 본창을 엽니다.
- **조용한 시작:** 자동 실행 중에는 업데이트 안내창을 띄우지 않습니다. 밝기 팝업과 키보드 제어는 본창을 열지 않아도 동작합니다.
- **설정 유지:** 기존 이름·밝기 대상·위젯 배치를 유지합니다. 위젯은 지정한 복원 설정을 따릅니다.
- **등록 정리:** 자동 실행을 끄거나 앱을 제거하면 이 설치 경로의 시작 항목을 정리합니다.

## 다운로드 및 업데이트

**[LumaDock-1.0.1.exe 다운로드](https://github.com/SCOTT0318/LumaDock/releases/download/v1.0.1/LumaDock-1.0.1.exe)** · [SHA-256 체크섬](https://github.com/SCOTT0318/LumaDock/releases/download/v1.0.1/SHA256SUMS.txt)

1.0.0에서는 앱의 **업데이트 확인 → 다운로드 및 설치**를 사용하거나, 트레이에서 기존 앱을 종료한 뒤 설치 EXE를 실행하세요. 설치 위치와 기존 설정은 유지됩니다. 설치에는 관리자 권한이 필요합니다.

**지원 환경:** Windows 10/11, .NET Framework 4.8 이상.

## 검증

**303개 검사 통과:** 기존 제어·위젯·업데이트 검사에 더해 자동 실행 등록 35개, 실행 설정 UI, 본창 비노출 시작 12개와 설정 저장·복원을 확인했습니다. 격리 검사에서는 실제 Windows 시작 항목이나 모니터 밝기를 변경하지 않았습니다.
