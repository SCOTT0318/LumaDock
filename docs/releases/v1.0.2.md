트레이의 전체 밝기 조절과 여러 모니터의 밝기 연동을 개선한 **LumaDock 1.0.2**입니다.

## 변경 사항

- **트레이 전체 밝기:** 작업 표시줄의 LumaDock 아이콘을 왼쪽 클릭하고 맨 위의 **전체 밝기** 슬라이더로 연결된 모니터를 같은 밝기로 조절합니다. 모니터별 슬라이더도 계속 사용할 수 있습니다.
- **함께 조절:** 키보드·Windows 연동과 전체 밝기는 모니터마다 변경 완료를 기다리던 방식에서 여러 모니터에 병렬로 요청하는 방식으로 바뀌었습니다.
- **연속 입력 처리:** 빠른 입력은 최신 값으로 합칩니다. 전체 조절과 개별 조절 사이의 이전 대기 명령도 취소하여 나중에 조절한 값이 유지됩니다.
- **모니터 통신:** 밝기 변경 뒤 반복 조회와 즉시 재전송을 줄였습니다. 통신에 실패한 외장 모니터는 추가 제어를 중지하며, 연결 확인 후 **다시 검색**하면 재개합니다. 한 모니터의 실패가 다른 모니터의 밝기 변경을 막지 않습니다.
- **Windows 중복 조절 방지:** Windows가 직접 제어하는 화면은 Windows 밝기를 우선 사용하고, 이미 변경된 화면에 같은 변화를 다시 적용하지 않습니다.
- **Windows 자동 실행:** **설정 → 실행 → Windows 시작 시 자동 실행**에서 설정합니다. 기본값은 켜짐이며 로그인 시 본창 없이 트레이에서 시작합니다.
- 기존 모니터 이름·밝기 대상·위젯 배치는 유지합니다.

HDMI 화면 잡음은 실제 환경에서 재현하지 못했습니다. 이번 변경은 앱의 제어 통신 부담과 실패 후 반복 요청을 줄이는 조치이며, 해당 잡음의 해결을 확인한 것은 아닙니다.

## 검증

**326개 검사 통과:** 앱 검사 303개와 격리된 설치·제거 검사 23개를 통과했습니다. 병렬 요청, 모니터별 실패 격리, 연속 입력 병합, 전체·개별 슬라이더 동기화, 팝업 닫기 시 적용, 자동 실행 등록과 트레이 시작을 확인했습니다. 자동 검사는 실제 모니터 밝기나 사용자의 Windows 시작 항목을 변경하지 않습니다.
