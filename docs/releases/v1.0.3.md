HDMI 제어 통신을 보호하고, 케이블을 다시 꽂기 전에 사용할 수 있는 신호 재초기화 기능을 추가한 **LumaDock 1.0.3**입니다.

## 변경 사항

- **HDMI 안정 모드:** 기본으로 켜집니다. 밝기·명암만 조회하고 통신 간격을 두며, 자동 재검색에서는 기존 제어 정보를 재사용합니다. 추가 기능이 필요하면 **설정 → HDMI 연결 안정성**에서 끌 수 있습니다.
- **실패한 연결 보호:** 이전에는 자동 재검색이 HDMI 통신 중지 상태를 초기화하여 같은 연결을 다시 조회할 수 있었습니다. 이제 이 상태를 재검색 뒤에도 유지하고, 중지된 연결에는 제어 요청을 보내지 않습니다.
- **HDMI 신호 복구:** **트레이 오른쪽 클릭 → HDMI 신호 복구 → 모니터 선택** 또는 본창의 복구 버튼을 사용합니다. Windows가 보고한 현재 화면 구성을 먼저 검증하고, 배치·해상도·주사율을 바꾸지 않는 동일 구성의 드라이버 재초기화를 요청합니다. 모든 화면이 잠깐 깜박일 수 있습니다.
- **대기 명령 차단:** 복구 전에 기존 모니터 핸들을 무효화하여 오래된 밝기 명령이 복구 후 다시 실행되지 않도록 했습니다. 복구가 실패하면 통신 중지 상태를 유지합니다.
- **진단 기록:** HDMI 명령·실패·복구 요청을 `%LocalAppData%\LumaDock\display.log`에 기록합니다. 화면을 바꾸지 않는 Windows 구성 검증 명령도 추가했습니다.
- 기존 전체 밝기·개별 밝기·Windows 자동 실행·모니터 이름·위젯 설정을 유지합니다.

HDMI 잡음의 실제 발생 원인은 아직 확정하지 못했습니다. 신호 재초기화 요청이 Windows에서 허용되는 것은 확인했지만, 잡음이 발생한 모니터가 이 기능으로 돌아오는지는 아직 검증하지 못했습니다. 모니터 내부 상태나 물리 연결 문제는 소프트웨어만으로 복구되지 않을 수 있습니다. 밝기 통신 실패를 화면 손상으로 단정하여 출력을 자동 초기화하지 않습니다.

**345개 검사 통과:** 앱 검사 322개와 격리 설치·제거 검사 23개. HDMI 통신 간격, 실패 상태 보존, 복구 실패 격리, 이전 핸들의 쓰기 차단, 설정 저장, 복구 메뉴와 제어 복원을 확인했습니다. 자동 검사는 실제 모니터 밝기나 화면 출력을 변경하지 않습니다.
